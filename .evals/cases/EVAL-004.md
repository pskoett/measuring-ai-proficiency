# EVAL-004: spec-refiner forbids closing keywords in plan PR bodies

## Scenario

A plan PR is generated by `spec-refiner` for a source issue. If its body contains `Closes #NN`, `Fixes #NN`, or `Resolves #NN` (or any verb tense of those), merging the plan PR will auto-close the source issue. This breaks the chain: `implementer-dispatcher` has nothing to assign, the source issue disappears from the board's active lanes, and the work stalls until a human re-opens it.

This happened on 2026-04-17 with plan PR #164 closing source issue #161 prematurely. Logged in `.learnings/ERRORS.md`.

## Regression path

The fix is an explicit prohibition in the spec-refiner instruction: a bullet that names the three verbs (`Closes`, `Fixes`, `Resolves`) and all their tenses, calls them out with `NEVER`, and warns that they close the linked issue on merge. This eval verifies that prohibition is still in the workflow source.

## Check

`.github/workflows/spec-refiner.md` must contain the literal string `Before finalizing the body, grep your own draft`. That phrase uniquely identifies the self-grep instruction on line 103 of the prompt, which in turn only exists as the tail of the prohibition bullet on line 101. If line 103 is still there, so is the prohibition.

Pattern chosen to avoid backtick and asterisk characters that trip frontmatter / shell quoting in the `eval-creator-ci` pipeline.

## Pass condition

`grep -qF 'Before finalizing the body, grep your own draft' .github/workflows/spec-refiner.md` exits with code 0.

## Fail condition

The self-grep instruction has been removed, which almost certainly means the prohibition bullet was deleted or rewritten. Plan PRs could once again include closing keywords and auto-close their source issues on merge.

## Adjacent rules worth testing (future evals)

- The Refs-only rule: body must contain `Refs #NN` and no closing verbs.
- Safe synonyms list: `Refs`, `For`, `Part of`, `Tracks`, `See` documented as allowed replacements.
- Self-grep step in the prompt: model is instructed to grep its own draft before finalizing.
